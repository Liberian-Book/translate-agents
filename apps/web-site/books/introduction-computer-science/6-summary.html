6.1 What Is an Operating System?

6.1 Hệ Điều Hành Là Gì?
  • An operating system (OS) is at the core of all of the connected hardware and software.
  • Hệ điều hành (OS) là trung tâm của tất cả phần cứng và phần mềm được kết nối.
  • Improving efficiency results in speeding up the implementation of applications from coding time and runtime standpoints. OSs have a large influence because of the abstractions/interfaces they implement.
  • Cải thiện hiệu suất dẫn đến việc tăng tốc độ triển khai các ứng dụng từ góc độ thời gian lập trình và thời gian chạy. Các hệ điều hành có ảnh hưởng lớn do các trừu tượng/giao diện mà chúng thực hiện.
  • Operating systems provide both mechanism and policy. Mechanism refers to a set of activities that you can do. Policy is how to use the mechanism in specific situations.
  • Hệ điều hành cung cấp cả cơ chế và chính sách. Cơ chế đề cập đến một tập hợp các hoạt động mà bạn có thể thực hiện. Chính sách là cách sử dụng cơ chế trong các tình huống cụ thể.
  • Virtualization in an operating system allows the system to run different applications that are handled by multiple users at a time on the same computer.
  • San ảo trong một hệ điều hành cho phép hệ thống chạy các ứng dụng khác nhau được xử lý bởi nhiều người dùng cùng lúc trên cùng một máy tính.
  • Server virtualization places a software layer called a hypervisor (e.g., virtual machine monitor or VMM) between a machine (e.g., server) hardware and the operating systems that run on it.
  • San ảo hóa máy chủ đặt một lớp phần mềm gọi là hypervisor (ví dụ: trình giám sát máy ảo hoặc VMM) giữa phần cứng của một máy (ví dụ: máy chủ) và các hệ điều hành chạy trên đó.
  • Using OS-level or server virtualization allows a server to run different types of operating systems at the same time on the same computer.
  • Sử dụng ảo hóa cấp OS hoặc ảo hóa máy chủ cho phép một máy chủ chạy các loại hệ điều hành khác nhau cùng lúc trên cùng một máy tính.
  • The OS translates from the hardware interface to the application interface and provides each running program with its own process.
  • Hệ điều hành dịch từ giao diện phần cứng sang giao diện ứng dụng và cung cấp cho mỗi chương trình đang chạy một tiến trình riêng.
  • A process consists of address space, one or more threads of control executing in that address space, and additional system state associated with it. The thread is a path of execution within a process and a process may contain multiple threads.
  • Một quá trình bao gồm không gian địa chỉ, một hoặc nhiều luồng điều khiển đang thực thi trong không gian địa chỉ đó, và trạng thái hệ thống bổ sung liên quan đến nó. Luồng là một con đường thực thi trong một quá trình và một quá trình có thể chứa nhiều luồng.
  • The instruction set architecture (ISA) defines a set of instructions that can be used to write assembly language programs that use the CPU while abstracting the hardware details from the program.
  • Kiến trúc tập lệnh (ISA) định nghĩa một tập hợp các lệnh có thể được sử dụng để viết các chương trình ngôn ngữ hợp ngữ mà sử dụng CPU trong khi trừu tượng hóa các chi tiết phần cứng khỏi chương trình.
  • OS functions guarantee protection, isolation, and sharing of resources efficiently via resource allocation and communication.
  • Các chức năng của hệ điều hành đảm bảo bảo vệ, cách ly và chia sẻ tài nguyên một cách hiệu quả thông qua việc phân bổ tài nguyên và giao tiếp.

6.2 Fundamental OS Concepts

6.2 Các Khái Niệm Cơ Bản Về Hệ Điều Hành
  • An OS manages computer resources (hardware) and provides services for computer programs (software).
  • Một hệ điều hành quản lý tài nguyên máy tính (phần cứng) và cung cấp dịch vụ cho các chương trình máy tính (phần mềm).
  • An OS is a complex system and executes many kinds of activities ranging from executing users’ programs, to running background jobs or scripts, to completing system programs.
  • Một hệ điều hành là một hệ thống phức tạp và thực hiện nhiều loại hoạt động, từ việc thực thi các chương trình của người dùng, đến việc chạy các công việc hoặc kịch bản nền, đến việc hoàn thành các chương trình hệ thống.
  • Processing involves a program, a process, and a processor. An OS is responsible for managing processes, and different OSs approach process management in different ways.
  • Xử lý liên quan đến một chương trình, một quy trình và một bộ xử lý. Một hệ điều hành (OS) có trách nhiệm quản lý các quy trình, và các hệ điều hành khác nhau tiếp cận việc quản lý quy trình theo những cách khác nhau.
  • The address space is the set of addresses generated by programs as they reference instructions and data. The memory space holds the actual main memory locations that are directly addressable for processing.
  • Không gian địa chỉ là tập hợp các địa chỉ được tạo ra bởi các chương trình khi chúng tham chiếu đến các lệnh và dữ liệu. Không gian bộ nhớ chứa các vị trí bộ nhớ chính thực tế mà có thể được truy cập trực tiếp để xử lý.
  • Computer memory consists of two main types: primary and secondary memory. An OS manages memory space through memory allocation and memory deallocation as well as by maintaining mappings from virtual addresses to physical and switching CPU context among addresses spaces.
  • Bộ nhớ máy tính bao gồm hai loại chính: bộ nhớ chính và bộ nhớ phụ. Một hệ điều hành quản lý không gian bộ nhớ thông qua việc phân bổ bộ nhớ và giải phóng bộ nhớ, cũng như duy trì các ánh xạ từ địa chỉ ảo đến địa chỉ vật lý và chuyển đổi ngữ cảnh CPU giữa các không gian địa chỉ.
  • Device drivers are the routines that interact directly with specific device types and related hardware to indicate how to initialize the device, request I/O, and handle interrupts or errors.
  • Các trình điều khiển thiết bị là các quy trình tương tác trực tiếp với các loại thiết bị cụ thể và phần cứng liên quan để chỉ ra cách khởi tạo thiết bị, yêu cầu I/O và xử lý ngắt hoặc lỗi.
  • A device register is the interface a device presents to a programmer, whereas each I/O device appears in the physical address space of the machine as a few words.
  • Một thanh ghi thiết bị là giao diện mà một thiết bị cung cấp cho lập trình viên, trong khi mỗi thiết bị I/O xuất hiện trong không gian địa chỉ vật lý của máy như một vài từ.
  • In an OS, it is important to have dual mode operations to ensure a high level of security and authority. The dual mode is responsible for separating the user from the kernel mode.
  • Trong một hệ điều hành, việc có các hoạt động chế độ kép là rất quan trọng để đảm bảo mức độ bảo mật và quyền hạn cao. Chế độ kép có trách nhiệm tách biệt người dùng khỏi chế độ nhân.
  • Successful OS designs have had a variety of architectures, such as monolithic, layered, microkernels, and virtual machine monitors. As the design of an OS—and even its role—are still evolving, it is simply impossible today to pick one “correct” way to structure an OS.
  • Các thiết kế hệ điều hành thành công đã có nhiều kiến trúc khác nhau, chẳng hạn như kiến trúc đơn thể, kiến trúc lớp, vi nhân và bộ giám sát máy ảo. Khi thiết kế của một hệ điều hành—và thậm chí cả vai trò của nó—vẫn đang phát triển, thật sự không thể chọn một cách "đúng" duy nhất để cấu trúc một hệ điều hành ngày nay.
  • A monolithic OS design is an OS architecture where the entire OS is working in kernel space.
  • Một thiết kế hệ điều hành đơn khối là một kiến trúc hệ điều hành mà toàn bộ hệ điều hành hoạt động trong không gian nhân.
  • A layered OS architecture consists of implementing the OS as a set of layers where each layer exposes an enhanced virtual machine to the layer above.
  • Một kiến trúc hệ điều hành theo lớp bao gồm việc triển khai hệ điều hành như một tập hợp các lớp, trong đó mỗi lớp cung cấp một máy ảo nâng cao cho lớp phía trên.
  • Hardware abstraction layer (HAL) is an example of layering in modern OSs. It allows an OS to interact with a hardware device at a general or abstract level rather than going deep into a detailed hardware level, which improves readability.
  • Lớp trừu tượng phần cứng (HAL) là một ví dụ về việc phân lớp trong các hệ điều hành hiện đại. Nó cho phép một hệ điều hành tương tác với một thiết bị phần cứng ở mức độ tổng quát hoặc trừu tượng thay vì đi sâu vào mức độ phần cứng chi tiết, điều này cải thiện khả năng đọc hiểu.
  • In a microkernel OS architecture, the functionality and capabilities are added to a minimal core OS.
  • Trong kiến trúc hệ điều hành microkernel, các chức năng và khả năng được thêm vào một hệ điều hành lõi tối thiểu.

6.3 Processes and Concurrency

6.3 Quy trình và Tính đồng thời
  • Concurrent processing is a computing model that improves performance when multiple processors are executing instructions simultaneously.
  • Xử lý đồng thời là một mô hình máy tính cải thiện hiệu suất khi nhiều bộ xử lý thực hiện các lệnh cùng một lúc.
  • A process consists of at least an address space, a CPU state, and a set of OS resources.
  • Một quá trình bao gồm ít nhất một không gian địa chỉ, một trạng thái CPU và một tập hợp các tài nguyên hệ điều hành.
  • The OS’s process namespace particulars depend on the specific OS, but in general, the name of a process is called a PID (process ID), which is a set of unique numbers that identify processes.
  • Các chi tiết về không gian tên tiến trình của hệ điều hành (OS) phụ thuộc vào hệ điều hành cụ thể, nhưng nói chung, tên của một tiến trình được gọi là PID (ID tiến trình), là một tập hợp các số duy nhất để xác định các tiến trình.
  • The OS maintains a data structure to keep track of a process state, which is called the process control block (PCB) or process descriptor.
  • Hệ điều hành duy trì một cấu trúc dữ liệu để theo dõi trạng thái của một tiến trình, được gọi là khối điều khiển tiến trình (PCB) hoặc mô tả tiến trình.
  • Concurrency refers to multiple activities and processes happening at the same time. An OS can achieve concurrent processing via the use of threads or one of three different processing environments: multiprogramming, multiprocessing, or distributed processing.
  • Concurrency đề cập đến nhiều hoạt động và quy trình diễn ra đồng thời. Một hệ điều hành có thể đạt được xử lý đồng thời thông qua việc sử dụng các luồng hoặc một trong ba môi trường xử lý khác nhau: đa chương trình, đa xử lý hoặc xử lý phân tán.
  • Scheduling is the act of determining which process is in the ready state and should be moved to the running state when more resources are requested than can be granted immediately, and in which order the requests should be serviced.
  • Lập lịch là hành động xác định quá trình nào đang ở trạng thái sẵn sàng và nên được chuyển sang trạng thái đang chạy khi có nhiều tài nguyên được yêu cầu hơn những gì có thể được cấp ngay lập tức, và theo thứ tự nào các yêu cầu nên được phục vụ.
  • A good scheduling algorithm minimizes response time, efficiently utilizes resources, and implements fairness by distributing CPU cycles equitably. Four simple scheduling algorithms are FCFS, RR, STCF, and SRPT.
  • Một thuật toán lập lịch tốt sẽ giảm thiểu thời gian phản hồi, sử dụng tài nguyên một cách hiệu quả và thực hiện sự công bằng bằng cách phân phối chu kỳ CPU một cách công bằng. Bốn thuật toán lập lịch đơn giản là FCFS, RR, STCF và SRPT.
  • Synchronization is a way of coordinating multiple concurrent activities that use a shared state.
  • Đồng bộ hóa là một cách để phối hợp nhiều hoạt động đồng thời sử dụng một trạng thái chung.
  • Allocation is a method that defines how data is stored in the memory by providing a set of requests for resources and identifying which processes should be given which resources to make the most efficient use of the resources. There are three main forms of allocation: contiguous allocation, linked allocation, and indexed allocation.
  • Phân bổ là một phương pháp xác định cách dữ liệu được lưu trữ trong bộ nhớ bằng cách cung cấp một tập hợp các yêu cầu về tài nguyên và xác định các quy trình nào nên được cấp tài nguyên nào để sử dụng tài nguyên một cách hiệu quả nhất. Có ba hình thức phân bổ chính: phân bổ liên tiếp, phân bổ liên kết và phân bổ chỉ mục.

6.4 Memory Management

6.4 Quản lý bộ nhớ
  • The OS loads executable files into memory, allows several different processes to share memory, and provides facilities for processes to exceed the memory size after they have started running.
  • Hệ điều hành tải các tệp thực thi vào bộ nhớ, cho phép nhiều tiến trình khác nhau chia sẻ bộ nhớ, và cung cấp các tiện ích để các tiến trình vượt quá kích thước bộ nhớ sau khi chúng đã bắt đầu chạy.
  • Memory multiplexing is dividing the capacity of the communication channel into multiple logical channels.
  • Bộ nhớ đa kênh là việc chia nhỏ dung lượng của kênh truyền thông thành nhiều kênh logic khác nhau.
  • There are several concepts that are critical to memory multiplexing, namely, isolation, sharing, virtualization, and utilization.
  • Có một số khái niệm rất quan trọng đối với việc đa hợp bộ nhớ, đó là cách ly, chia sẻ, ảo hóa và sử dụng.
  • Time slicing is a time frame for each process to run in a preemptive multitasking CPU such that each process will be run every single time slice.
  • Phân chia thời gian là một khung thời gian cho mỗi quá trình chạy trong một CPU đa nhiệm có thể ngắt, sao cho mỗi quá trình sẽ được thực thi trong mỗi khoảng thời gian.
  • Sharing means that multiple processes can share the same piece of data concurrently.
  • Chia sẻ có nghĩa là nhiều tiến trình có thể chia sẻ cùng một mảnh dữ liệu đồng thời.
  • Memory sharing improves the performance of the system because the data is not copied from one address space to another, so memory allocation is done only once.
  • Chia sẻ bộ nhớ cải thiện hiệu suất của hệ thống vì dữ liệu không bị sao chép từ không gian địa chỉ này sang không gian địa chỉ khác, do đó việc cấp phát bộ nhớ chỉ được thực hiện một lần.
  • Virtualization is a technique that gives an application the impression that it has its own logical memory and that it is independent from the available physical memory.
  • San ảo là một kỹ thuật cho phép một ứng dụng có cảm giác rằng nó có bộ nhớ logic riêng và rằng nó độc lập với bộ nhớ vật lý có sẵn.
  • Fragmentation is a problem where the memory blocks cannot be allocated to the processes due to their small individual size and the distribution of sizes in the pool; there might be enough total free memory to satisfy the demand, but the available chunks cannot be allocated contiguously.
  • Phân mảnh là một vấn đề mà các khối bộ nhớ không thể được phân bổ cho các tiến trình do kích thước nhỏ riêng lẻ của chúng và sự phân bố kích thước trong bể; có thể có đủ bộ nhớ trống tổng cộng để đáp ứng nhu cầu, nhưng các khối có sẵn không thể được phân bổ liên tục.
  • Linkers combine many separate pieces of a program, reorganize storage allocation so that all the pieces can fit together, and touch up addresses so that the program can run under the new memory organization.
  • Các trình liên kết kết hợp nhiều phần riêng biệt của một chương trình, tổ chức lại việc phân bổ bộ nhớ sao cho tất cả các phần có thể khớp với nhau, và điều chỉnh địa chỉ để chương trình có thể chạy dưới tổ chức bộ nhớ mới.
  • There are two basic operations used in dynamic storage management to manage a memory or storage to satisfy various needs: allocate a block with a given number of bytes or free a previously allocated block.
  • Có hai thao tác cơ bản được sử dụng trong quản lý bộ nhớ động để quản lý bộ nhớ hoặc lưu trữ nhằm đáp ứng các nhu cầu khác nhau: cấp phát một khối với một số byte nhất định hoặc giải phóng một khối đã được cấp phát trước đó.
  • Virtual memory is a key component of the operating system for ensuring process isolation by guaranteeing that each process gets its own view of the memory.
  • Bộ nhớ ảo là một thành phần quan trọng của hệ điều hành để đảm bảo sự cách ly giữa các tiến trình bằng cách đảm bảo rằng mỗi tiến trình có cái nhìn riêng của nó về bộ nhớ.

6.5 File Systems

6.5 Hệ thống Tập tin
  • A file system is responsible for defining file names, storing files on a storage device, and retrieving files from a storage device.
  • Hệ thống tệp có trách nhiệm định nghĩa tên tệp, lưu trữ tệp trên thiết bị lưu trữ và truy xuất tệp từ thiết bị lưu trữ.
  • File systems define operations on objects such as create, read, and write, and they may also provide higher-level services, such as accounting and quotas, incremental backup indexing or search, file versioning, and encryption.
  • Hệ thống tệp xác định các thao tác trên các đối tượng như tạo, đọc và ghi, và chúng cũng có thể cung cấp các dịch vụ cấp cao hơn, chẳng hạn như kế toán và hạn ngạch, lập chỉ mục sao lưu gia tăng hoặc tìm kiếm, phiên bản tệp và mã hóa.
  • File systems are concerned with lower-level characteristics such as performance and failure resilience.
  • Hệ thống tệp quan tâm đến các đặc điểm cấp thấp hơn như hiệu suất và khả năng chống chịu với sự cố.
  • The file system interface defines standard operations such the creation and deletion of files (or directories), manipulation of files and directories, copy, and lock.
  • Giao diện hệ thống tệp xác định các thao tác tiêu chuẩn như tạo và xóa tệp (hoặc thư mục), thao tác với tệp và thư mục, sao chép và khóa.
  • File systems are responsible for managing parts of the disk that are used (inodes) and parts of the disk that are not used (free blocks).
  • Hệ thống tệp chịu trách nhiệm quản lý các phần của đĩa được sử dụng (inodes) và các phần của đĩa không được sử dụng (khối trống).
  • A distributed file system (DFS) is a file system that is distributed on multiple file servers or multiple locations that support network-wide sharing of files and devices.
  • Hệ thống tệp phân tán (DFS) là một hệ thống tệp được phân tán trên nhiều máy chủ tệp hoặc nhiều vị trí hỗ trợ chia sẻ tệp và thiết bị trên toàn mạng.
  • A DFS provides an abstraction over physical disks that is akin to the abstraction that virtual memory provides over physical memory.
  • Một DFS cung cấp một sự trừu tượng trên các đĩa vật lý tương tự như sự trừu tượng mà bộ nhớ ảo cung cấp trên bộ nhớ vật lý.

6.6 Reliability and Security

6.6 Độ tin cậy và Bảo mật
  • We consider an OS to be reliable if it delivers service without errors or interruptions.
  • Chúng ta coi một hệ điều hành là đáng tin cậy nếu nó cung cấp dịch vụ mà không có lỗi hoặc gián đoạn.
  • Protection is a general mechanism used throughout the OS and for all resources needed to be protected such as memory, processes, files, devices, CPU time, and network bandwidth.
  • Bảo vệ là một cơ chế chung được sử dụng trong toàn bộ hệ điều hành và cho tất cả các tài nguyên cần được bảo vệ như bộ nhớ, quy trình, tệp, thiết bị, thời gian CPU và băng thông mạng.
