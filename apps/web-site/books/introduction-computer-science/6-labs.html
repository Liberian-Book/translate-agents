Tạo một hệ thống tệp trên một đám mây mà bạn chọn và gắn nó như một ổ đĩa trên máy tính của bạn. Thực hiện một số thí nghiệm với các ứng dụng khác nhau mà bạn chọn để xác định xem hiệu suất có chấp nhận được hay không. Thử nghiệm với chức năng SaaS được cung cấp trên các đám mây lớn khác nhau khi bạn làm việc trên phòng thí nghiệm này.

Examples with SaaS:

Ví dụ với SaaS:

  • Office suites: Use SaaS offerings like Google Workspace or Microsoft 365 to create and edit documents. Observe the responsiveness of these services.
  • Bộ ứng dụng văn phòng: Sử dụng các dịch vụ SaaS như Google Workspace hoặc Microsoft 365 để tạo và chỉnh sửa tài liệu. Quan sát sự phản hồi của những dịch vụ này.
  • Development tools: Experiment with cloud-based IDEs like AWS Cloud9 or GitHub Codespaces to develop and run code. Pay attention to the execution speed and any latency in the development process.
  • Công cụ phát triển: Thử nghiệm với các IDE dựa trên đám mây như AWS Cloud9 hoặc GitHub Codespaces để phát triển và chạy mã. Chú ý đến tốc độ thực thi và bất kỳ độ trễ nào trong quá trình phát triển.
  • Database management: Work with a cloud-based database service like Amazon RDS. Perform queries and updates to test performance.
  • Quản lý cơ sở dữ liệu: Làm việc với dịch vụ cơ sở dữ liệu dựa trên đám mây như Amazon RDS. Thực hiện các truy vấn và cập nhật để kiểm tra hiệu suất.
  • Analytics: Utilize services like AWS QuickSight or Looker Studio to perform data analysis tasks. Evaluate the speed of data processing and visualization rendering.
  • Phân tích: Sử dụng các dịch vụ như AWS QuickSight hoặc Looker Studio để thực hiện các nhiệm vụ phân tích dữ liệu. Đánh giá tốc độ xử lý dữ liệu và hiển thị trực quan.
5 .
Research the recovery features that are available on your computer’s OS and document what you would need to do in case of a system crash. Create a recovery disk as needed so that you are prepared for the worst.
