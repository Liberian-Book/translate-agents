1 .

Rosetta Code is an archive of computing tasks and source code written in many different languages that accomplish the same task. Explore the page about converting numbers into Roman numerals and study the source code written in 8080 assembly (low-level), C (middle-level), and JavaScript (high-level). Compare and contrast the following aspects of the code:

Rosetta Code là một kho lưu trữ các nhiệm vụ lập trình và mã nguồn được viết bằng nhiều ngôn ngữ khác nhau để thực hiện cùng một nhiệm vụ. Khám phá trang về việc chuyển đổi số thành số La Mã và nghiên cứu mã nguồn được viết bằng ngôn ngữ lắp ráp 8080 (mức thấp), C (mức trung bình) và JavaScript (mức cao). So sánh và đối chiếu các khía cạnh sau của mã:

  1. Length
  2. Chiều dài
  3. Readability: how easy is it to understand how the code works?
  4. Dễ đọc: mã dễ hiểu như thế nào?
  5. Level of abstraction
  6. Mức độ trừu tượng
  7. Structured or unstructured
  8. Có cấu trúc hoặc không có cấu trúc
