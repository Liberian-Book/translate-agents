4.1 Models of Computation

4.1 Mô hình Tính toán
  • A computational model defines what an algorithm or program does. There are hardware models, programming language models, and abstract models.
  • Một mô hình tính toán xác định những gì một thuật toán hoặc chương trình thực hiện. Có các mô hình phần cứng, mô hình ngôn ngữ lập trình và mô hình trừu tượng.
  • Low-level programming means writing machine code that can be understood by a CPU directly, or something very near to that. It is laborious but yields very fast code.
  • Lập trình cấp thấp có nghĩa là viết mã máy mà CPU có thể hiểu trực tiếp, hoặc điều gì đó rất gần với điều đó. Nó tốn công sức nhưng mang lại mã rất nhanh.
  • Middle-level programming is a compromise that is reasonably efficient and more convenient than low-level programming.
  • Lập trình cấp trung là một sự thỏa hiệp mà có hiệu suất hợp lý và thuận tiện hơn so với lập trình cấp thấp.
  • High-level programming is more abstract and intuitive for humans. It is less labor-intensive, but high-level code can be slower than low-level code.
  • Lập trình cấp cao thì trừu tượng và trực quan hơn cho con người. Nó ít tốn công sức hơn, nhưng mã cấp cao có thể chậm hơn mã cấp thấp.
  • Programming language paradigms are approaches for organizing source code.
  • Các mô hình ngôn ngữ lập trình là những cách tiếp cận để tổ chức mã nguồn.
  • In the imperative paradigm, code orders the CPU to execute specific actions.
  • Trong mô hình mệnh lệnh, mã lệnh cho CPU thực hiện các hành động cụ thể.
  • In the declarative paradigm, the programmer declares the outcome that they need.
  • Trong mô hình khai báo, lập trình viên khai báo kết quả mà họ cần.
  • In the functional paradigm, the programmer defines mathematical functions to evaluate.
  • Trong mô hình hàm, lập trình viên định nghĩa các hàm toán học để đánh giá.
  • In structured programming, the flow of execution is specified with explicit syntax elements (“if-then-else,” “for” loop, “while” loop) and never GOTO.
  • Trong lập trình có cấu trúc, luồng thực thi được chỉ định bằng các phần tử cú pháp rõ ràng (“if-then-else,” vòng lặp “for,” vòng lặp “while”) và không bao giờ sử dụng GOTO.
  • In procedural programming, a program is divided into procedures. Each procedure performs one specific task and has a descriptive name.
  • Trong lập trình quy trình, một chương trình được chia thành các quy trình. Mỗi quy trình thực hiện một nhiệm vụ cụ thể và có một tên mô tả.
  • In object-oriented programming, the basic building block is an object. An object combines data and procedures that together represent a human concept.
  • Trong lập trình hướng đối tượng, khối xây dựng cơ bản là một đối tượng. Một đối tượng kết hợp dữ liệu và quy trình mà cùng nhau đại diện cho một khái niệm của con người.

4.2 Building C Programs

4.2 Xây dựng các chương trình C
  • The C programming language is the most prominent example of a low-level language. Programs written in C typically execute as fast as assembly language and allow programmers to directly manipulate machine features such as memory via the use of pointers.
  • Ngôn ngữ programming language C là ví dụ nổi bật nhất về một ngôn ngữ cấp thấp. Các chương trình được viết bằng C thường thực thi nhanh như ngôn ngữ hợp ngữ và cho phép lập trình viên trực tiếp thao tác với các tính năng của máy như bộ nhớ thông qua việc sử dụng con trỏ.
  • The C programming language is used by most of the system software we depend on today (e.g., operating systems, compilers, interpreters, and device drivers) because of its efficient execution, portability, and modularity.
  • Ngôn ngữ lập trình C được sử dụng bởi hầu hết các phần mềm hệ thống mà chúng ta phụ thuộc vào ngày nay (ví dụ: hệ điều hành, trình biên dịch, trình thông dịch và trình điều khiển thiết bị) vì khả năng thực thi hiệu quả, tính di động và tính mô-đun của nó.
  • The C data model supports the creation of a variety of basic types including integers and floating point numbers, as well as pointers. C also provides type constructors used to create collections using the array, struct, and union keywords.
  • Mô hình dữ liệu C hỗ trợ việc tạo ra nhiều loại kiểu cơ bản khác nhau bao gồm số nguyên và số thực, cũng như con trỏ. C cũng cung cấp các bộ tạo kiểu được sử dụng để tạo ra các tập hợp bằng cách sử dụng từ khóa array, struct, và union.
  • C supports the imperative and structured/procedural programming paradigms and allows for conditional and iterative statements as well as functions, which can leverage recursion.
  • C hỗ trợ các mô hình lập trình mệnh lệnh và có cấu trúc/procedural programming và cho phép các câu lệnh điều kiện và lặp lại cũng như các hàm, có thể tận dụng recursion.
  • Program development steps in C require designing algorithms, developing programs that implement algorithms, and compiling, linking, and executing programs. All of these steps may be performed within a C development environment, which is a suite of tools that a programmer uses to create software. It must include a text editor, compiler, and linker, and may include other tools such as a version control manager, and others.
  • Các bước phát triển chương trình trong C yêu cầu thiết kế các thuật toán, phát triển các chương trình thực hiện các thuật toán, và biên dịch, liên kết, và thực thi các chương trình. Tất cả các bước này có thể được thực hiện trong một môi trường phát triển C, là một bộ công cụ mà một lập trình viên sử dụng để tạo ra phần mềm. Nó phải bao gồm một trình soạn thảo văn bản, trình biên dịch, và linker, và có thể bao gồm các công cụ khác như một trình quản lý kiểm soát phiên bản, và những công cụ khác.
  • A development environment may be an assemblage of separate command-line programs, or an IDE, which is a development environment bundled into a single app. There are a multitude of C development environments, and many of them are free to use.
  • Một môi trường phát triển có thể là một tập hợp các chương trình dòng lệnh riêng biệt, hoặc một IDE, là một môi trường phát triển được gói gọn trong một ứng dụng duy nhất. Có rất nhiều môi trường phát triển C, và nhiều trong số đó là miễn phí để sử dụng.
  • Compiling C programs involves converting C into assembly language, which can itself be translated into machine code. This process is performed by using a combination tools known respectively as a C compiler, assembler, and linker. The GCC compiler is an open-source C compiler developed by the GNU project, it include gcc, ar, and ld to implement compiling, assembly, and linking.
  • Biên dịch các chương trình C liên quan đến việc chuyển đổi C thành ngôn ngữ hợp ngữ, mà chính nó có thể được dịch thành mã máy. Quy trình này được thực hiện bằng cách sử dụng một tập hợp các công cụ được gọi lần lượt là trình biên dịch C, trình hợp ngữ và trình liên kết. Trình biên dịch GCC là một trình biên dịch C mã nguồn mở được phát triển bởi dự án GNU, nó bao gồm gcc, ar và ld để thực hiện biên dịch, hợp ngữ và liên kết.
  • Linking is the process of combining the .o files that result from separate C modules into one deliverable library or executable program.
  • Linking là quá trình kết hợp các tệp .o được tạo ra từ các mô-đun C riêng biệt thành một thư viện hoặc chương trình thực thi có thể phát hành.
  • A library is a file that contains the object code of compiled functions. There are several variations of libraries (static, dynamic, shared) and ways of linking them (load-time, run-time).
  • Một thư viện là một tệp chứa mã đối tượng của các hàm đã biên dịch. Có nhiều biến thể của thư viện (tĩnh, động, chia sẻ) và các cách liên kết chúng (thời gian tải, thời gian chạy).
  • Version control tools manage the files created in programming, facilitating collaboration, backups, and undoing errors.
  • Công cụ kiểm soát phiên bản quản lý các tệp được tạo ra trong lập trình, tạo điều kiện cho sự hợp tác, sao lưu và khôi phục lỗi.

4.4 Applications of Programming Models

4.4 Các Ứng Dụng của Các Mô Hình Lập Trình
  • Low-level and middle-level programming will continue to be important as society increasingly relies on low-powered computing devices and IoT.
  • Lập trình cấp thấp và cấp trung sẽ tiếp tục quan trọng khi xã hội ngày càng phụ thuộc vào các thiết bị tính toán công suất thấp và IoT.
  • Middle-level languages including C are ideal for developing firmware and kernels.
  • Các ngôn ngữ cấp trung, bao gồm C, là lý tưởng để phát triển firmware và kernels.
  • Rust is a relatively new middle-level language that is gaining traction.
  • Rust là một ngôn ngữ trung cấp tương đối mới đang ngày càng được ưa chuộng.
  • Arduino is an embedded computer platform. Arduino firmware can be written in C.
  • Arduino là một nền tảng máy tính nhúng. Firmware của Arduino có thể được viết bằng ngôn ngữ C.
  • Raspberry Pi kernels can be developed in C.
  • Hạt nhân Raspberry Pi có thể được phát triển bằng ngôn ngữ C.
