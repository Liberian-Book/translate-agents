Creating a Todo Web Application with Bootstrap and Django

Tạo ứng dụng web Todo với Bootstrap và Django

The Todo web application in this subsection uses Bootstrap and Django. Bootstrap’s CSS templates are used for the UI features. Django serves as both the front end and back end. Django templates are part of the user interface to get and set data via HTTP requests. Incoming requests are then handled by an API built using the Django REST Framework.

Ứng dụng web Todo trong phần này sử dụng Bootstrap và Django. Các mẫu CSS của Bootstrap được sử dụng cho các tính năng giao diện người dùng. Django đóng vai trò là cả giao diện phía trước và phía sau. Các mẫu Django là một phần của giao diện người dùng để lấy và thiết lập dữ liệu thông qua các yêu cầu HTTP. Các yêu cầu đến sau đó được xử lý bởi một API được xây dựng bằng cách sử dụng Django REST Framework.

Define the Todo Model

Định nghĩa Mô hình Todo

Once you register and install the ToDo web application, you will be able to create todo tasks, which can be assigned categories. The next step is to create the models. Two models will be created for Category and TodoList. Open the todo/models.py file and add the code shown.

Khi bạn đăng ký và cài đặt ứng dụng web ToDo, bạn sẽ có thể tạo các nhiệm vụ todo, có thể được gán các danh mục. Bước tiếp theo là tạo các mô hình. Hai mô hình sẽ được tạo cho Category và TodoList. Mở tệp todo/models.py và thêm mã được hiển thị.

# -*- coding: utf-8 -*-
from __future__ import unicode_literals

from django.db import models
from django.utils import timezone

# Create your models here.
class Category(models.Model):

  name = models.CharField(max_length=100)

  class Meta:
    verbose_name = ("Category")
    verbose_name_plural = ("Categories")

  def __str__(self):
    return self.name

class TodoList(models.Model):
  title = models.CharField(max_length=250)
  content = models.TextField(blank=True)
  created = models.DateField(default=timezone.now().strftime("%Y-%m-%d"))
  due_date = models.DateField(default=timezone.now().strftime("%Y-%m-%d"))
  category = models.ForeignKey(Category, default="General", on_delete=models.DO_NOTHING)
  class Meta:
    ordering = ["-created"] # order by most recently created
  def __str__(self):
    return self.title

The Category and TodoList Python classes describe the properties for the models for Category and TodoList tables, respectively. The TodoList model contains a ForeignKey field to the Category model. Each todo item will be associated with one category. After creating the models, a migration file needs to be generated to create the physical tables in the database. To generate the migration file, run the following command:

Các lớp Python Category và TodoList mô tả các thuộc tính cho các mô hình của bảng Category và TodoList, tương ứng. Mô hình TodoList chứa một trường ForeignKey đến mô hình Category. Mỗi mục todo sẽ được liên kết với một danh mục. Sau khi tạo các mô hình, một tệp di chuyển cần được tạo ra để tạo các bảng vật lý trong cơ sở dữ liệu. Để tạo tệp di chuyển, hãy chạy lệnh sau:

Creating the Serializers

Tạo các Bộ tuần tự

The next step is to implement two serializers, one for the Category model and one for the TodoList model. A serializer is a tool to control response outputs and convert complex data into content, such as JSON. In the todo/ directory, create the file, serializers.py, and add the code shown in the code snippet that follows. The serializer classes inherit from serializers.ModelSerializer because this class creates the serializer, with fields corresponding to the Model fields defined earlier. Each serializer specifies the Model to work with and the fields to be included in the JSON object, which are all fields.

Bước tiếp theo là triển khai hai bộ tuần tự, một cho mô hình Category và một cho mô hình TodoList. Một serializer là một công cụ để kiểm soát đầu ra phản hồi và chuyển đổi dữ liệu phức tạp thành nội dung, chẳng hạn như JSON. Trong thư mục todo/, hãy tạo tệp serializers.py và thêm mã được hiển thị trong đoạn mã sau. Các lớp serializer kế thừa từ serializers.ModelSerializer vì lớp này tạo ra bộ tuần tự, với các trường tương ứng với các trường của mô hình đã được định nghĩa trước đó. Mỗi bộ tuần tự chỉ định mô hình để làm việc và các trường sẽ được bao gồm trong đối tượng JSON, đó là tất cả các trường.

# todo/serializers.py

from rest_framework import serializers
from .models import TodoList, Category

class CategorySerializer(serializers.ModelSerializer):
  class Meta:
    model = Category
    fields = "__all__"

class TodoSerializer(serializers.ModelSerializer):
  class Meta:
    model = TodoList
    fields = "__all__"

Sau khi bạn tạo mỗi serializer, bước tiếp theo là tạo một hàm View tương ứng cho cả serializer Category và serializer Todo. Để làm điều này, hãy mở todo/views.py và thêm mã được hiển thị trong đoạn mã sau. Lớp viewsets, cung cấp một triển khai mặc định của các thao tác CRUD, được nhập từ rest_framework. Các lớp CategoryView và TodoView cung cấp một queryset của các danh mục và các mục todo, tương ứng. Chúng cũng chỉ định serializer_class được định nghĩa trong phần trước.

# -*- coding: utf-8 -*-
from __future__ import unicode_literals

from django.shortcuts import render,redirect
from rest_framework import viewsets
from .serializers import TodoSerializer, CategorySerializer
from .models import TodoList, Category
import datetime

# Create your views here.

class CategoryView(viewsets.ModelViewSet):
  queryset = Category.objects.all()
  serializer_class = CategorySerializer

class TodoView(viewsets.ModelViewSet):
  queryset = TodoList.objects.all()
  serializer_class = TodoSerializer

Todo items are dependent on categories. To perform CRUD operations on the Category table, click on the categories API path, as shown in Figure 11.22.

Các mục Todo phụ thuộc vào các danh mục. Để thực hiện các thao tác CRUD trên bảng Danh mục, hãy nhấp vào đường dẫn API danh mục, như được hiển thị trong Hình 11.22.

Once you access the Category List page, enter a category name in the field near the bottom of the page and click the Post button to save it. You can add additional category names. Once you save each name using the Post button, the categories will appear in JSON format, as illustrated in Figure 11.23.

Khi bạn truy cập trang Danh sách Danh mục, hãy nhập tên danh mục vào trường gần dưới cùng của trang và nhấn nút Đăng để lưu lại. Bạn có thể thêm các tên danh mục bổ sung. Khi bạn lưu mỗi tên bằng nút Đăng, các danh mục sẽ xuất hiện ở định dạng JSON, như được minh họa trong Hình 11.23.

To ensure that categories can be updated or deleted as needed, the primary key, which is “id”, must be included in the API path (e.g., /api/categories/{id}/). For example, to update or delete the category with id=3, the API path is /api/categories/3/. As shown in Figure 11.24, once this category is pulled up on the Category Instance page, the DELETE button is visible at the top to delete the category. If the category needs to be updated, the PUT button visible near the bottom can be used for updates.

Để đảm bảo rằng các danh mục có thể được cập nhật hoặc xóa khi cần, khóa chính, tức là “id”, phải được bao gồm trong đường dẫn API (ví dụ: /api/categories/{id}/). Ví dụ, để cập nhật hoặc xóa danh mục có id=3, đường dẫn API là /api/categories/3/. Như được thể hiện trong Hình 11.24, khi danh mục này được hiển thị trên trang Thể hiện Danh mục, nút DELETE sẽ xuất hiện ở trên cùng để xóa danh mục. Nếu danh mục cần được cập nhật, nút PUT xuất hiện gần dưới cùng có thể được sử dụng để cập nhật.

Next, navigate back to the API root. Click on the todos API path to see, as outlined in Figure 11.25, that a Todo item has a Category field that appears as a drop-down list of categories. The CRUD operations also can be performed on the TodoList table. This will be done next through the user interface via templates.

Tiếp theo, điều hướng trở lại gốc API. Nhấp vào đường dẫn API todos để xem, như đã nêu trong Hình 11.25, rằng một mục Todo có trường Danh mục xuất hiện dưới dạng danh sách thả xuống các danh mục. Các thao tác CRUD cũng có thể được thực hiện trên bảng TodoList. Điều này sẽ được thực hiện tiếp theo thông qua giao diện người dùng qua các mẫu.

Creating the View

Tạo Giao Diện

The next step is to create the View. The View function is needed for template pages, which are created in the next section. The View function is also needed to interact with the database to both create and delete todo items.

Bước tiếp theo là tạo View. Hàm View cần thiết cho các trang mẫu, được tạo ra trong phần tiếp theo. Hàm View cũng cần thiết để tương tác với cơ sở dữ liệu nhằm tạo và xóa các mục todo.

To create the View, open the todo/views.py file and add the code shown in the following code snippet. This code takes an HTTP request object. If the request method is POST, a todo item is either created or deleted, depending on which button is clicked. Otherwise, the request method is GET and the todo items are displayed to the user.

Để tạo View, hãy mở tệp __HTML_TAG_0__todo/views.py__HTML_TAG_1__ và thêm mã được hiển thị trong đoạn mã sau. Mã này nhận một đối tượng yêu cầu HTTP. Nếu phương thức yêu cầu là POST, một mục todo sẽ được tạo hoặc xóa, tùy thuộc vào nút nào được nhấn. Nếu không, phương thức yêu cầu là GET và các mục todo sẽ được hiển thị cho người dùng.

def index(request): # index view
  todos = TodoList.objects.all() # query all todos with object manager
  categories = Category.objects.all() # get all categories with object manager
  if request.method == "POST": # check if request method is POST
    if "taskAdd" in request.POST: # check if request is to add a todo item
      title = request.POST["description"] # title
      date = str(request.POST["date"]) # date
      category = request.POST["category_select"] # category
      content = title + " -- " + date + " " + category # content
      Todo = TodoList(title=title, content=content, due_date=date, category=Category.objects.get(name=category))
      Todo.save() # save todo item
      return redirect("/") # reload page
    if "taskDelete" in request.POST: # check if request is to delete a todo
      checkedlist = request.POST["checkedbox"] # checked todos to be deleted
      for todo_id in checkedlist:
        todo = TodoList.objects.get(id=int(todo_id)) # get todo id
        todo.delete() # delete todo
  return render(request, "index.html", {"todos": todos, "categories":categories})

$ python manage.py runserver

Next, launch a browser and navigate to http://localhost:8000. The page highlighted in Figure 11.27 should appear.

Tiếp theo, khởi động một trình duyệt và điều hướng đến http://localhost:8000. Trang được làm nổi bật trong Hình 11.27 sẽ xuất hiện.

To create a todo list, fill out the form and click the Add Task button as shown in Figure 11.28.

Để tạo một danh sách công việc, hãy điền vào mẫu và nhấn nút Thêm Công Việc như được hiển thị trong Hình 11.28.

In addition, the todo item should also be viewable in the API that was created. This should appear as outlined in Figure 11.29.

Ngoài ra, mục todo cũng nên có thể xem được trong API đã được tạo. Điều này nên xuất hiện như đã được phác thảo trong Hình 11.29.
