11.1 Modern Web Applications Architectures

11.1 Kiến trúc Ứng dụng Web Hiện đại
  • The Web is defined by phases, each denoted by its principal usage—Web 1.0 for reading content, Web 2.0 regarding social interaction, and Web 3.0 as an open, decentralized, and trusted web.
  • Web được định nghĩa bởi các giai đoạn, mỗi giai đoạn được biểu thị bằng cách sử dụng chính—Web 1.0 để đọc nội dung, Web 2.0 liên quan đến tương tác xã hội, và Web 3.0 là một web mở, phi tập trung và đáng tin cậy.
  • Traditional web architectures rendered web pages on the server, with each client request resulting in a new HTML page being sent from the server to the browser. The Model-View-Controller (MVC) pattern was often used for server-side development.
  • Kiến trúc web truyền thống tạo ra các trang web trên máy chủ, với mỗi yêu cầu của khách hàng dẫn đến một trang HTML mới được gửi từ máy chủ đến trình duyệt. Mô hình-Miền-Kiểm soát (MVC) thường được sử dụng cho phát triển phía máy chủ.
  • Responsive web applications render effectively in a browser regardless of the user’s device screen or orientation.
  • Các ứng dụng web đáp ứng hiển thị hiệu quả trong trình duyệt bất kể màn hình hoặc hướng của thiết bị người dùng.
  • Single-page applications (SPAs) load one web page in the browser, manipulating the UI and fetching data through APIs. This is often done with JavaScript making AJAX calls to REST APIs.
  • Các ứng dụng một trang (SPAs) tải một trang web trong trình duyệt, thao tác giao diện người dùng và lấy dữ liệu thông qua các API. Điều này thường được thực hiện bằng JavaScript thực hiện các cuộc gọi AJAX đến các API REST.
  • Native mobile applications are designed to run on a specific device. They have the advantage of performance and access to data and functionality on the device but suffer from a lack of cross-platform support.
  • Các ứng dụng di động gốc được thiết kế để chạy trên một thiết bị cụ thể. Chúng có lợi thế về hiệu suất và truy cập vào dữ liệu cũng như chức năng trên thiết bị nhưng gặp bất lợi do thiếu hỗ trợ đa nền tảng.
  • Web 3.0 is the next phase of the Web. Technologies that will be needed to support it will likely include distributed ledger technologies and AI.
  • Web 3.0 là giai đoạn tiếp theo của Web. Các công nghệ cần thiết để hỗ trợ nó có thể bao gồm công nghệ sổ cái phân tán và trí tuệ nhân tạo.
  • Future web architectures will likely see a combination of Web 2.0 and 3.0 architectural models to support decentralization, openness, trust, cost, and performance effectively. This hybrid approach solves some problems while not fully addressing the goals of Web 3.0.
  • Các kiến trúc web trong tương lai có khả năng sẽ thấy sự kết hợp giữa các mô hình kiến trúc Web 2.0 và 3.0 để hỗ trợ hiệu quả việc phân quyền, tính mở, sự tin cậy, chi phí và hiệu suất. Cách tiếp cận kết hợp này giải quyết một số vấn đề trong khi không hoàn toàn đáp ứng được các mục tiêu của Web 3.0.

11.2 Sample Responsive WAD with Bootstrap and Django

11.2 Mẫu WAD Phản hồi với Bootstrap và Django
  • Bootstrap is an open-source, responsive web application framework, and Django is a Python-based web application development framework. Both frameworks are highly popular due to their ease of use.
  • Bootstrap là một framework ứng dụng web mã nguồn mở, phản hồi, và Django là một framework phát triển ứng dụng web dựa trên Python. Cả hai framework đều rất phổ biến nhờ vào sự dễ sử dụng của chúng.
  • To build the Todo application, you must install Python, PIP, Django, Django REST Framework, Bootstrap, and jQuery.
  • Để xây dựng ứng dụng Todo, bạn phải cài đặt Python, PIP, Django, Django REST Framework, Bootstrap và jQuery.
  • The steps to build the Todo application are install and set up a local programming environment for Python 3, download and install Python 3.9.4, and add Python and its Scripts subfolder to your path environment data.
  • Các bước để xây dựng ứng dụng Todo là cài đặt và thiết lập một môi trường lập trình cục bộ cho Python 3, tải xuống và cài đặt Python 3.9.4, và thêm Python cùng với thư mục con Scripts của nó vào dữ liệu môi trường đường dẫn của bạn.
  • The first step to build a Django web application is to create a Django project.
  • Bước đầu tiên để xây dựng một ứng dụng web Django là tạo một dự án Django.
  • Once the Django project is successfully completed and set up, the next step is to create the Todo application and register it in the Django project.
  • Khi dự án Django đã hoàn thành và được thiết lập thành công, bước tiếp theo là tạo ứng dụng Todo và đăng ký nó trong dự án Django.
  • After registering and installing the Todo web application, the next step is to create the models for Category and TodoList.
  • Sau khi đăng ký và cài đặt ứng dụng web Todo, bước tiếp theo là tạo các mô hình cho Category và TodoList.
  • After the Category and TodoList models are created, the next step is to create the serializers, the View, routers, user interface, and templates.
  • Sau khi các mô hình Category và TodoList được tạo ra, bước tiếp theo là tạo các bộ tuần tự (serializers), View, bộ định tuyến (routers), giao diện người dùng và các mẫu (templates).

11.3 Sample Responsive WAD with Bootstrap/React and Node

11.3 Mẫu WAD phản hồi với Bootstrap/React và Node
  • React is a JavaScript library popular to build user interfaces.
  • React là một thư viện JavaScript phổ biến để xây dựng giao diện người dùng.
  • Node is a JavaScript runtime environment that provides developers with the tools to develop web applications, as well as servers, scripts, and command-line tools.
  • Node là một môi trường chạy JavaScript cung cấp cho các nhà phát triển các công cụ để phát triển ứng dụng web, cũng như máy chủ, tập lệnh và công cụ dòng lệnh.
  • When creating a Todo web application using React and Node, React serves as the front end, handling the user interface, as well as getting and setting data via HTTP requests using Axios. Node serves as the back end, using a REST API built with ExpressJS and the MongooseJS ODM to interact with a MongoDB database.
  • Khi tạo một ứng dụng web Todo sử dụng React và Node, React đóng vai trò là phần giao diện người dùng, xử lý giao diện người dùng, cũng như lấy và thiết lập dữ liệu thông qua các yêu cầu HTTP sử dụng Axios. Node đóng vai trò là phần phía máy chủ, sử dụng một REST API được xây dựng với ExpressJS và MongooseJS ODM để tương tác với cơ sở dữ liệu MongoDB.
  • To build the Todo application using Bootstrap, React, and Node, you need React v17.0.2, Bootstrap v4.5.0, Node v14.17.5, ExpressJS v4.17.2, MongooseJS v6.1.9, and Axios v0.21.0.
  • Để xây dựng ứng dụng Todo sử dụng Bootstrap, React và Node, bạn cần React v17.0.2, Bootstrap v4.5.0, Node v14.17.5, ExpressJS v4.17.2, MongooseJS v6.1.9 và Axios v0.21.0.

    • build the controller

    • thiết lập API REST

    • tạo giao diện front end React
    • create the React app
    • tạo ứng dụng React

    • cài đặt Bootstrap và các phụ thuộc khác

    • kết nối giao diện front end React với back end Node

11.4 Sample Responsive WAD with Bootstrap/React and Django

11.4 Mẫu WAD đáp ứng với Bootstrap/React và Django
  • The Todo web application can be updated using Bootstrap with React and Django.
  • Ứng dụng web Todo có thể được cập nhật bằng cách sử dụng Bootstrap với React và Django.
  • For this version of the Todo web application, React serves as the front end handling the user interface to get and set data via HTTP requests. Django serves as the back end.
  • Đối với phiên bản này của ứng dụng web Todo, React đóng vai trò là phần giao diện người dùng để lấy và thiết lập dữ liệu thông qua các yêu cầu HTTP. Django đóng vai trò là phần phía sau.
  • To build the Todo application using Bootstrap with React and Django, you need Python v3.9.4, PIP v21.3.1, Django v4.0.1, Django REST Framework v3.13.1, Bootstrap v4.5.0, Django-cors-headers v3.11.0, React v17.0.2, and Axios v0.21.0.
  • Để xây dựng ứng dụng Todo sử dụng Bootstrap với React và Django, bạn cần Python v3.9.4, PIP v21.3.1, Django v4.0.1, Django REST Framework v3.13.1, Bootstrap v4.5.0, Django-cors-headers v3.11.0, React v17.0.2, và Axios v0.21.0.
  • The React application uses Axios to fetch data by making requests to a given endpoint.
  • Ứng dụng React sử dụng Axios để lấy dữ liệu bằng cách gửi yêu cầu đến một điểm cuối nhất định.
  • A proxy to the Django application helps tunnel API requests from the React application to http://localhost:8000, where the Django application will receive and handle the requests.
  • Một proxy đến ứng dụng Django giúp chuyển tiếp các yêu cầu API từ ứng dụng React đến http://localhost:8000, nơi ứng dụng Django sẽ nhận và xử lý các yêu cầu.

11.6 Sample Ethereum Blockchain Web 2.0/Web 3.0 Application

11.6 Mẫu ứng dụng Blockchain Ethereum Web 2.0/Web 3.0
  • A simple Todo application can be created using React with Web 3.0 powered by Ethereum smart contracts on the blockchain.
  • Một ứng dụng Todo đơn giản có thể được tạo ra bằng cách sử dụng React với Web 3.0 được hỗ trợ bởi các hợp đồng thông minh Ethereum trên blockchain.
  • The Ethereum blockchain creates a secure peer-to-peer network through the use of smart contracts, which are secure digital agreements that enable users to transact directly with each other via the Web.
  • Blockchain Ethereum tạo ra một mạng lưới ngang hàng an toàn thông qua việc sử dụng hợp đồng thông minh, là những thỏa thuận kỹ thuật số an toàn cho phép người dùng giao dịch trực tiếp với nhau qua Web.
  • Building the Todo Ethereum blockchain Web 3.0 application requires React v17.0.2, Bootstrap v4.5.0, Node v14.17.5, Web 3.js v1.2.2, Truffle v5.0.2, Solidity v0.8.11, and Ganache.
  • Xây dựng ứng dụng Web 3.0 Todo Ethereum yêu cầu React v17.0.2, Bootstrap v4.5.0, Node v14.17.5, Web 3.js v1.2.2, Truffle v5.0.2, Solidity v0.8.11, và Ganache.
  • The Truffle Framework, which is a suite of tools popular to develop smart contracts, can be used to develop the Ethereum smart contract.
  • Khung Truffle, là một bộ công cụ phổ biến để phát triển hợp đồng thông minh, có thể được sử dụng để phát triển hợp đồng thông minh Ethereum.
  • The Truffle Framework can be implemented using Solidity, which is a high-level, object-oriented language that is focused on the implementation of smart contracts.
  • Khung Truffle có thể được triển khai bằng cách sử dụng Solidity, là một ngôn ngữ cấp cao, hướng đối tượng, tập trung vào việc triển khai các hợp đồng thông minh.
